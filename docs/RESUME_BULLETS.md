# Resume Bullets: OptiTwinAI

- Built OptiTwinAI, a full-stack warehouse digital twin platform combining deterministic simulation, optimiser comparisons, RL policy training, dashboard analytics, and report generation.
- Implemented a FastAPI/SQLAlchemy backend with React/Vite/Tailwind frontend for scenario modelling, what-if analysis, convergence/stability analytics, and strategy comparison.
- Designed the optimisation layer to compare classical optimisers with an experimental fractional-inspired gradient-memory method while documenting limitations honestly.
