# OptiTwinAI

Full-stack digital twin AI platform for warehouse and supply-chain optimisation with FastAPI, React, simulation, optimisation, RL, analytics, and reports.

## Project Type

Full-stack AI decision platform

## Why It Stands Out

- Warehouse digital twin simulation with capacity, queues, priority orders, robot failures, cost, throughput, utilisation, and strategy metrics.
- Optimisation lab comparing Gradient Descent, noisy SGD-style updates, Adam, and an experimental fractional-inspired optimiser.
- Tabular Q-learning policy training, evaluation, and rule-based strategy comparison.
- FastAPI backend, SQLAlchemy persistence, React/Vite/Tailwind frontend, dashboard analytics, and Markdown report generation.

## Tech and Skills

Python, FastAPI, SQLAlchemy, SQLite, React, TypeScript, Vite, Digital Twins, Optimisation, Reinforcement Learning, Analytics

## Getting Started

~~~powershell
cd backend && python -m venv .venv && .\.venv\Scripts\activate && pip install -r requirements.txt
~~~

~~~powershell
uvicorn app.main:app --reload
~~~

~~~powershell
cd frontend && npm install && npm run dev
~~~
